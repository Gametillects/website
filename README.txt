DDCNorth website export

This ZIP contains the complete static website, including HTML, CSS,
JavaScript, inline SVG logos, and embedded Inter and Space Mono fonts.

OPEN LOCALLY
Unzip the archive and open index.html in your browser.

PUBLISH ON YOUR OWN HOST
Upload index.html, the assets folder, and the licenses folder to your
web root. No package installation or build step is required.
Update the og:url metadata in index.html if your website address changes.

EDIT
index.html               Page content, inline styles, logos, and fonts
assets/header.css        Header and navigation styles
assets/header.js         Navigation, search, and interaction behavior
assets/footer.css        Footer styles
licenses/                Licenses for the bundled fonts

The contact links open the visitor's email app. The exported site does
not require a server or an external asset download.
